# プライバシーポリシー

> 本ポリシーはドラフトです。公開前に運営者・専門家による確認が必要です。

【運営者名】（以下「運営者」）は、本サービスにおける個人情報の取扱いについて、以下のとおり定めます。

## 1. 取得する情報
- お問い合わせ・掲載申請時に入力いただく氏名、メールアドレス、問い合わせ内容等
- アクセスログ（IPアドレス、閲覧ページ、日時、ブラウザ情報等）
- 本サービスに掲載する事業者・公的機関の情報（名称、所在地、電話番号、Web サイトの URL、対応言語等）。これらは、事業者からの掲載申請のほか、官公庁等が公開するオープンデータおよび事業者自身が Web サイト等で公開している情報から取得することがあります。

## 2. 利用目的
- お問い合わせへの対応
- 掲載申請の審査・連絡
- 外国語で利用できるサービスを利用者が探せるよう、事業者・公的機関の情報を本サービスに掲載すること
- 掲載情報の正確性の確認および更新
- 不正利用の防止およびセキュリティの確保
- 本サービスの改善のための統計分析

## 3. 第三者提供
法令に基づく場合を除き、本人の同意なく個人データを第三者に提供しません。なお、本サービスが掲載する事業者情報のうち個人に関する情報（個人事業主の氏名等）は、本人の同意を得た場合に限り掲載します。法人・公的機関の情報は個人情報に当たらない範囲で掲載します。

## 4. 掲載情報の取得方法と出典
1. 運営者は、官公庁等が公開するオープンデータを、それぞれの利用条件に従って利用し、掲載ページに出典を表示します。
2. 運営者は、事業者が自ら公開している Web サイトから、対応言語・連絡先の確認のために情報を自動的に取得することがあります。この際、robots.txt 等のサイトの指示に従い、サーバーに負荷をかけない間隔で取得します。取得の方法と停止のご依頼は「クローラーについて」のページをご覧ください。
3. 取得した Web ページのデータは、確認のために一時的に保存し、一定期間（30 日）経過後に削除します。Web ページの文章や画像を本サービスに転載することはありません。
4. 掲載する情報は運営者が確認したうえで公開し、確認した日を掲載ページに表示します。

## 5. 委託
運営者は、利用目的の達成に必要な範囲で、クラウドサービス事業者等に個人情報の取扱いを委託することがあります。この場合、委託先を適切に監督します。

## 6. 安全管理
運営者は、個人情報の漏えい・滅失・毀損を防止するため、通信の暗号化、アクセス制御等の安全管理措置を講じます。

## 7. 開示・訂正・削除等の請求
本人から個人情報の開示・訂正・利用停止・削除の請求があった場合、本人確認のうえ、法令に従い対応します。下記窓口までご連絡ください。

掲載されている事業者ご本人は、各掲載ページの「掲載情報の修正・削除を依頼」から、掲載内容の訂正・掲載の停止を依頼できます。運営者は、ご本人であることを確認のうえ、原則として受付から 7 日以内に対応します。掲載を停止した事業者の情報は、以後の自動取得の対象から除外します。

## 8. Cookie 等
本サービスは、利便性向上やアクセス解析のために Cookie 等を使用することがあります。ブラウザの設定により無効にできます。
