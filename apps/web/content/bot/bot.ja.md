# クローラーについて

> 本ページはドラフトです。公開前に運営者・専門家による確認が必要です（確定文言は F-119 で反映）。

本サービス「在日外国人向けサービス検索」は、在日外国人が外国語で利用できるサービスを探せるよう、事業者が公開している Web サイトから対応言語と連絡先を確認するプログラム（クローラー）を運用しています。

- User-Agent: `bizshow-collector/0.1`（このページへのリンクを含みます）
- robots.txt の指示に従います。同じサイトへのアクセスは 10 秒以上の間隔をあけ、1 回の確認で取得するページは 3 ページまでです。
- ログインが必要なページやフォームの送信は行いません。
- 取得したページは確認のためだけに使い、30 日以内に削除します。文章や画像を転載することはありません。
- クロールの停止、掲載の修正・削除をご希望の場合は、[お問い合わせフォーム]({{contactUrl}})からご連絡ください。停止をご依頼いただいたサイトは、以後アクセスしません。
